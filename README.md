# Страница авторизации (Основы CSS)

Верстка формы входа по макету: Flexbox-центрирование, фоновое изображение,
стилизация полей и кнопки.

## Структура
- `index.html` — разметка страницы;
- `css/style.css` — стили;
- `img/background.jpg` — фон (город в облаках).

## Запуск
1. Склонируйте репозиторий: `git clone <ссылка>`
2. Положите любое фото города в `img/background.jpg`
   (или используйте ссылку на своё изображение в `style.css`).
3. Откройте `index.html` в браузере.
